# Changelog — writing-style skill

All notable changes to the skill and to `STYLE.md`. Newest first.

## 1.1.4 — 2026-07-05

- §23 Learned Preferences: four additions from Nick's KoreaDiscount edit round —
  no stage-direction openers; cut dramatic pivot mini-sentences; hedge claims
  about others' beliefs ("seemed to treat", "popularly named") while leaving
  data statements unhedged; drop unneeded "rather than X" contrast tails.
  STYLE_VERSION 1.1.3 -> 1.1.4; skill version 1.1.3 -> 1.1.4.

## 1.1.3 — 2026-07-03

- §23 Learned Preferences: added a rule to use declarative titles and section
  headings rather than questions (source: KoreaDiscount paper edit round).
  STYLE_VERSION 1.1.2 -> 1.1.3; skill version 1.1.2 -> 1.1.3.

## 1.1.2 — 2026-06-18

- §23 Learned Preferences: added a rule not to force the "not X, but Y" reframe
  where the contrast is not load-bearing (prefer a plain declarative). Refines
  §3/§21. STYLE_VERSION 1.1.1 -> 1.1.2; skill version 1.1.1 -> 1.1.2.

## 1.1.1 — 2026-06-17

- §23 Learned Preferences: added a rule to avoid defensive hedge words
  ("honestly", "truthfully", "to be honest", "frankly", "briefly and honestly").
  STYLE_VERSION 1.1.0 -> 1.1.1; skill version 1.1.0 -> 1.1.1.

## 1.1.0 — 2026-06-16

- Added §21 "Concision and Clarity Discipline (Strunk and White)" to `STYLE.md`:
  omit needless words, active voice, positive form, specific/concrete language,
  plain words, parallel form, one-idea paragraphs, plus a needless-words cut list
  and a Nick-domain before/after. Includes guardrails so it does not flatten the
  "not X, but Y" reframe or strip argumentative nuance.
- Renumbered Final Style Checklist (now §22) and Learned Preferences (now §23);
  updated `SKILL.md` references and added a concision rule to the highest-leverage
  list. STYLE_VERSION 1.0.0 -> 1.1.0.

  `nick_alonso_writing_style_guide.md` (curated core §1–21).

  memory-loop protocol in `SKILL.md`.
- Canonical in the `SnM` repo; published to user-level `~/.cursor/skills/` and
