# Inbox

Drop raw material here: notes, pasted reading, links, half-formed ideas. One file per
drop, any format. This folder is git-ignored and never deployed.

To process it, say "ingest inbox" (or hand a file over in chat). The knowledge-base
skill in `.cursor/skills/knowledge-base/` decides, for each idea, whether it becomes a
new note in `content/notes/` or enriches an existing one, and proposes the change as a
diff for review. Nothing is written without that review.

After a drop is processed, delete it or move it to `inbox/processed/`.
